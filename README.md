#  Онлайн платформа-торговой сети электроники

В рамках учебного проекта реализована бэкенд-часть веб-приложения,
онлайн платформы-торговой сети электроники.



## Возможности

- 📧 Создание и управление звеньями сети и их продуктами
- 🔐 Разграничение прав пользователей
- 🔗 Работа с PostgreSQL
- 📝 Веб-приложение с API-интерфейсом и админ-панелью.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/V-nika-viktorovna/electronics_retail_chain.git
   ```
2. Создайте и активируйте виртуальное окружение:

    ```bash
    python -m venv venv
    ```
3. Установите зависимости:
   
   ```bash
    pip install -r requirements.txt
    ```

4. Настройте переменные окружения:
    ```bash
    .env.example
    ```
5. Локальный запуск проекта:

   ```bash
    python manage.py runserver
    ```

6. Ручной deploy на удаленном сервере:

   ```bash
    В разработке

   ```

## Структура проекта
```
electronics_retail_chain/
├── .venv                     # виртуальная среда Python
│
├── config/                   # конфигурационные файлы
│
├── electronics_retail_chain  # основное приложение проекта
│   ├── migrations/           # миграции базы данных
│   │   
│   ├── admin.py              # регистрация моделей в админ панели Django
│   ├── apps.py               # объявление приложения
│   ├── models.py             # определение моделей данных
│   ├── pagination.py         # реализация кастомной постраничной навигации
│   ├── serializers.py        # сериализация данных для REST API
│   ├── tests.py              # модуль для юнит-тестов
│   ├── urls.py               # конфигурация URL маршрутов
│   └── views.py              # контроллеры и обработчики запросов
│
├── users/                    # отдельное приложение для работы с пользователями
│
├── .env                      # скрытый файл с переменными окружения
├── .env.example              # шаблон для файла .env
├── .flake8                   # настройки для linter Flake8
├── .gitignore                # игнорируемые Git файлы
├── coverage.txt              # файл покрытия тестами 
├── manage.py                 # основной управляющий скрипт Django
├── README.md                 # описание проекта
└── requirements.txt          # зависимости проекта

```
